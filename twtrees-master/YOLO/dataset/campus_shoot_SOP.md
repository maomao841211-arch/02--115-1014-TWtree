# 校園實拍 SOP — 補齊缺資料的排放源類別

> 目的：公開資料集補不到的 5 個類別，靠校園實地拍攝補足。此文件給拍攝者一份可照做的流程：
> **拍什麼、怎麼拍、拍幾張、怎麼去識別化、檔案放哪**。標註規範另見 `classes.md`。

## 0. 為什麼要自己拍
下列類別公開資料集沒有、或標的不符（詳見 `SOURCES.md`），且校園實拍最貼近本工具的部署場域：

| 類別 | 缺的原因 |
|------|---------|
| `gas_cylinder (9)` 實驗室高壓氣體鋼瓶 | GasC_test 全是桶裝瓦斯瓶，無實驗室細長高壓鋼瓶 |
| `boiler (1)` 鍋爐 | 無公開資料集 |
| `brush_cutter (3)` 除草機／割草機 | 無公開資料集 |
| `gas_stove (0)` 整台瓦斯爐 | 公開資料集只標火焰/旋鈕，非整台 |
| `ac_outdoor (10)` 冷氣室外機 | 公開資料集多為室內機＋多邊形標註 |

## 1. 每類拍攝張數目標（分階段）
對齊 `classes.md` 的分階段策略：

| 階段 | 每類張數 | 用途 |
|------|---------|------|
| probe | ~50 | 先驗證「拍→標→訓練→匯出→瀏覽器」整條鏈路可行 |
| MVP | 150–300 | 初版可用模型 |
| 正式 | 500+ | 穩定精度（校園實拍為主力） |

**先做 probe**：每類先拍約 50 張、標一標、丟進訓練跑一輪，確認流程順了再擴量。不要一次衝 500 張才發現角度/標註方式要改。

## 2. 怎麼拍才有用（提高模型泛化）
同一個目標物，**變換條件多拍幾張**，比拍很多張一模一樣的更有價值：

- **距離**：近（物件占畫面 ~60%）、中（~30%）、遠（~10–15%）各拍幾張。手機掃描時距離不定，模型要都認得。
- **角度**：正面、左右斜 45°、稍微俯視/仰視。繞著物件拍一圈最好。
- **光線**：室內日光燈、戶外晴天、陰天/傍晚各拍。避免全部同一時段同一盞燈。
- **背景**：同一台機器在不同背景（牆邊、走廊、堆雜物旁）各拍，避免模型把背景當特徵。
- **遮擋**：部分被管線/雜物/人擋住的也拍幾張（真實場景常被擋）。
- **同型多台**：校園若有多台同類（多台室外機、多支鋼瓶），盡量都拍，增加外觀多樣性。

**反例（避免）**：站原地連拍 50 張幾乎相同的照片——對訓練幾乎沒幫助。

## 3. 各類別拍攝重點
- **gas_cylinder (9) 實驗室鋼瓶**：實驗室/準備室常見的細長高壓鋼瓶（N₂、O₂、Ar、CO₂ 等），連同鋼瓶固定架、瓶帽一起入鏡。整支框（含瓶身，不要只框瓶帽）。
- **boiler (1) 鍋爐**：熱水鍋爐/蒸氣鍋爐本體，含管線接口。機房光線常不足，開燈或補光。
- **brush_cutter (3) 除草機**：背負式/手推式割草機。停放與（若安全且有人操作時）使用中都可拍；注意安全距離。
- **gas_stove (0) 整台瓦斯爐**：廚房/家政教室整台爐（雙口/單口/檯面爐），**框整台爐體**，不是只框火焰。開火與關火狀態都拍。
- **ac_outdoor (10) 冷氣室外機**：**室外機（壓縮機那台，非室內壁掛機）**。牆面、屋頂、地面架設的各拍；單台與並排多台都拍。

## 4. ⚠️ 去識別化紅線（拍到人一定要處理）
校園拍攝常入鏡師生 → **一律先打碼再進任何會外流的資料夾**。

1. **原始檔（含臉、未打碼）只放 `_local/`**，此資料夾已 gitignore，**絕不進 public repo**。
2. 用 `scripts/blur_faces.py` 對人臉打碼後，才放進 `dataset/images/`。
3. 打碼腳本設計為**輸出到另一資料夾**，不覆蓋原始檔（保護原檔紅線）。
4. 避免拍到可識別個資：識別證、車牌、門牌/教室名牌 → 構圖時盡量避開，或事後打碼。
5. 若目標物本身無關人（如屋頂室外機、機房鍋爐），優先選沒有人入鏡的角度，省去打碼。

## 5. 檔案放哪、命名
- 原始含臉檔：`YOLO/_local/raw_campus/<class>/`（gitignore，不外流）
- 打碼後待標註：`YOLO/dataset/raw/<class>/`（gitignore）
- 標註完成：`YOLO/dataset/images/{train,val}/`＋`labels/{train,val}/`（gitignore；train:val = 8:2）
- 建議檔名：`<class>_campus_<3位序號>.jpg`，例如 `boiler_campus_001.jpg`。

## 6. 拍完的下一步
1. 打碼（`blur_faces.py`）。
2. 標註：用 LabelImg / Roboflow / CVAT 等，**整體物件框**，class id 依 `data.yaml`（見 `classes.md` 對照）。
3. 依 8:2 分 train/val，放進 `dataset/`。
4. 先跑 probe 訓練驗證流程（見 `../training/train.md`），再決定是否擴量到正式張數。
